00 / INTRO

일상의 순간을 텍스트와 사진으로 기록하고, 언제든 다시 꺼내볼 수 있도록 만든 개인 기록형 메모 앱.

BUILDHTML · CSS · VANILLA JAVASCRIPT
DATALOCALSTORAGE · INDEXEDDB
APPSERVICE WORKER · PWA / MANIFEST
01 / WHY

복잡한 기능보다, 필요한 순간 빠르게 기록하고 사진과 함께 다시 찾아볼 수 있는 개인 메모 경험을 목표로 했다.

02 / CORE FEATURES
  1. 01 TEXT + PHOTO 텍스트 메모에 최대 10장까지 사진을 함께 기록. 목록 카드에는 첨부 장수를 배지로 표시.
  2. 02 GALLERY 첨부한 사진을 라이트박스로 확대하고, 이전 / 다음 이동과 현재 위치 카운터를 제공.
  3. 03 NAVIGATION SPA 방식으로 화면을 전환하고 히스토리를 처리. 기록 목록은 정렬해서 다시 찾을 수 있음.
  4. 04 LOCAL DATA 텍스트는 LocalStorage, 이미지는 IndexedDB에 저장해 브라우저 안에서 기록이 유지됨.
03 / BUILD

HTML / CSS와 Vanilla JavaScript로 기능을 직접 구현하고, 텍스트 기반 데이터는 LocalStorage, 이미지 데이터는 IndexedDB를 사용해 저장 역할을 분리했다.

Service Worker와 Manifest를 적용해 PWA 구조로 확장했다.
