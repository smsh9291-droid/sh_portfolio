MIVY

PERSONAL MEMO WEB APPMOBILE-FIRST PWAFUNCTIONAL BUILD
01 / OVERVIEW

일상의 순간을 텍스트와 사진으로 기록하고, 언제든 다시 꺼내볼 수 있도록 만든 개인 기록형 메모 앱.

복잡한 기능보다, 필요한 순간 빠르게 기록하고 사진과 함께 다시 찾아볼 수 있는 개인 메모 경험을 목표로 했다. 서버 없이 브라우저 안에서 동작하며, 모바일 화면을 기준으로 설계했다.

TYPEPERSONAL MEMO WEB APP · PWA
ROLEPLANNING · UI DESIGN · FRONT-END · AI COLLABORATION
BUILDHTML · CSS · VANILLA JAVASCRIPT (ES MODULES)
DATALOCALSTORAGE · INDEXEDDB
APPSERVICE WORKER · WEB APP MANIFEST
02 / CORE FEATURES
  1. 01 RECORD 메모 날짜는 캘린더 팝업에서 고르고, 감정은 최대 3개까지, 태그는 Enter로 추가한다.
  2. 02 PHOTO 메모당 최대 10장. 앨범 선택과 카메라 촬영 버튼을 나누고, 썸네일로 미리 보며 한 장씩 삭제한다.
  3. 03 VIEWER 상세 화면 갤러리에서 사진을 누르면 라이트박스로 확대. 위치 카운터, 이전 / 다음 버튼, 스와이프, 방향키와 ESC를 지원한다.
  4. 04 CALENDAR 메모가 있는 날짜에 점을 표시하고, 날짜를 누르면 그날 기록한 메모 목록을 보여준다.
03 / IMPLEMENTATION

프레임워크와 외부 라이브러리 없이 HTML / CSS / Vanilla JavaScript ES Module로 화면, 상태, 저장소 계층을 나눠 구현했다.
